Privacy policy

Effective October 14, 2026

Commuter is a personal train-schedule automation operated by the GitHub account itsazndy. This policy describes the automation and this information website.

Information accessed and used

The automation uses public train timetable data, the owner's configured route and departure preferences, sender and recipient email addresses, a selected calendar identifier, and OAuth credentials. It compares weekly schedules, creates or updates its schedule events for calendar subscription, and sends a weekly digest listing changed times or confirming an unchanged schedule against an available prior-week baseline. When no comparable prior-week report exists, the digest explains that it is establishing a baseline.

Google's gmail.send permission permits sending email as the authorized account. Commuter does not request permission to read the Gmail inbox. The calendar.events.owned permission allows access to and management of events on calendars the account owns; the automation uses it to retrieve and create or update its own managed events in the configured calendar.

Storage and retention

Renewable OAuth credentials are kept in a local credentials file during setup and in encrypted GitHub Actions repository secrets for scheduled execution. Credentials are loaded into the runner during a job and are not deliberately written to job logs or committed to the source repository.

Schedule snapshots, comparison results, prepared event and email content, recipient details, and delivery identifiers may be stored in the owner's private automation repository to support comparisons and prevent duplicate delivery. That repository's history retains prior versions until the owner removes them. Preview artifacts are configured to expire after seven days. Operational logs are retained according to the repository's GitHub Actions retention settings. Messages and calendar events remain in Google services and recipients' accounts until those account holders delete them.

Sharing and service providers

Google processes the account authorization, outgoing emails, and calendar events. GitHub hosts this information site and runs and stores the private automation. The configured email recipient receives the schedule digest. The owner's calendar application can access the schedule through a private calendar subscription; anyone with that subscription link can view the calendar. Calendar invitations are currently disabled. Commuter does not sell Google user data, use it for advertising, or send it to AI models for processing or training.

Commuter's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Control, revocation, and deletion

The owner can disable the scheduled GitHub workflow, remove the Google credentials secret and local token file, and revoke the app's access in Google Account connections. Revocation stops future authorized access but does not automatically remove existing email, calendar events, repository history, or copies already delivered to recipients. The owner can remove retained data using the relevant service's deletion controls.

This website

This static site contains no sign-in form, analytics scripts, tracking cookies, or collection forms. GitHub Pages may process IP addresses and standard request information to provide hosting and security, as described in GitHub's privacy statement.

Contact and updates

For support or privacy questions, use the support address shown on the Google consent screen or the project support page. GitHub issues are public; do not post account credentials or other private information. This page will be updated if the automation's data practices change.
